# Noctra Launcher

Noctra Launcher is an independent Minecraft: Java Edition launcher for Windows.

## Features

- Microsoft account authentication
- Minecraft ownership verification
- Vanilla and Fabric profiles
- Modrinth integration
- Isolated Minecraft profiles
- Custom launcher interface
- Per-profile RAM and Java settings
- Mod and resource pack management

## About

Noctra Launcher is designed to provide a clean, customizable launcher experience for Minecraft: Java Edition.

Users sign in with their own Microsoft account and must own Minecraft to use Minecraft services.

Noctra Launcher does not collect or store Microsoft account passwords.
